PRINCE NICK DATA HUB — STARTER WEBSITE

WHAT IS INCLUDED
- Responsive website homepage
- MTN, Telecel and AT network selector
- Sample bundle cards (prices intentionally not populated)
- Order preview and Ghanaian phone-number format validation
- PWA manifest and service worker for installable web-app support

IMPORTANT
This is a front-end starter/demo. It does NOT collect money, create live orders,
connect to a telecom supplier, or deliver data. Do not advertise it as live vending
until the server-side backend, verified payment webhooks, supplier API, order
reconciliation, refunds, security controls and privacy information are implemented
and tested.

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser to preview the basic website.
3. For PWA installation and service-worker testing, host the folder on an HTTPS
   website (or use localhost during development). A PWA cannot be installed
   reliably by opening the file directly.

BEFORE LAUNCH
- Replace support@example.com with a real support address.
- Confirm actual network packages and wholesale prices with an authorized supplier.
- Add a secure backend; never put supplier or payment secret keys in app.js.
- Configure payment provider callbacks/webhooks and verify payment server-side.
- Confirm supplier API coverage for MTN, Telecel and AT and test delivery statuses.
- Add terms, privacy notice, refund policy and contact details.
- Have an eligible adult/business owner complete provider onboarding and compliance.
